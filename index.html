આ વેબસાઇટનું સિદ્ધાંત

1. એક ગામ, એક લિંક

ગામવાસીઓને અલગ-અલગ સરકારી વેબસાઇટ શોધવાની જરૂર ન પડે.

2. Source સાથે આંકડો

દરેક મહત્વના આંકડા સાથે source અને last-updated date.

3. Verified ≠ Estimate

અંદાજ અને સત્તાવાર આંકડા સ્પષ્ટ રીતે અલગ રહેશે.

4. Public + Admin

Public page view-only; data editing માટે અલગ secure admin/database.
